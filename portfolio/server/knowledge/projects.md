## Museum Heist: AI Guard Lab

Museum Heist: AI Guard Lab is a 3D stealth demo built with Three.js and JavaScript, built with Claude. It has a guard AI state machine with PATROL, CHASE and SEARCH states, waypoint patrols, a detection radius, last-known-position search and a loot mechanic.

## WebCraft

WebCraft is a voxel sandbox built with Three.js and JavaScript, built with Claude. It has procedural terrain, chunked meshing and collision. Players can break and place blocks, use a hotbar, and sprint or fly.

## Neon Vault

Neon Vault is a 3D browser escape-room game built with Three.js, Vite and JavaScript, built with Claude. It has ordered objectives, a timer, a score and a live HUD. The code is modular: game state, an event bus, a game loop and UI components.

## Hospital Management System

The Hospital Management System is a team academic project. Ali and his team developed a responsive web-based hospital management system using HTML, CSS, PHP and MySQL. Ali implemented CRUD functionality for doctor records with backend integration. The project strengthened his teamwork and problem-solving skills in a real-world scenario.

## Projects that use Three.js

Ali has built three projects with Three.js: Museum Heist: AI Guard Lab, WebCraft and Neon Vault. All three are browser-based 3D games, built with Claude. His other project, the Hospital Management System, is a PHP and MySQL web application.
